# Use Cases & Project Ideas

Final showcase projects (short)

1) Enterprise Policy RAG Assistant
- Problem: employees can’t quickly find policy answers
- Features: citations, confidence hints, no-answer mode
- Stack: .NET 10, Azure OpenAI, Azure AI Search

2) Multi-Agent Helpdesk Copilot with MCP
- Problem: support requests need routing and tool access
- Features: supervisor + specialists + MCP tools (ticket, KB, user lookup)
- Stack: .NET 10, Semantic Kernel, MCP server/client

3) Incident Commander Assistant
- Problem: slow incident triage and communication
- Features: summarize logs, propose next steps, draft stakeholder updates
- Stack: Azure Monitor + LLM orchestration + tool calling
